⚙ ProMail Tracker — Settings

Must start with https:// (spam filters distrust http pixels). No trailing slash needed.

How it stays out of spam

  1. Only one 1×1 image is added to each email — nothing else in your message is changed.
  2. The pixel URL is clean HTTPS with no query strings, redirects, or cookies.
  3. No hidden display:none tricks — just a plain tiny image, the most filter-friendly form.
  4. If the server is down, your email is sent completely untouched.

Note: the pixel itself is spam-neutral. Inbox placement still depends on your sending domain's reputation (SPF/DKIM/DMARC), subject lines, and sending volume — keep those healthy as usual.

👤 Google account

Sign in with Google to protect your tracking data: the link lets you restore everything — tracks, detections and reports — after reinstalling the extension or moving to another computer.

Checking sign-in status…

The extension only uses your Google identity (account ID + email) — it never reads your Gmail. Sign-out only clears this browser's session; your data stays linked to your Google account so a future sign-in restores it.

🔔 Tracking preferences

Used to display report dates and detection times. Timestamps are always stored in UTC.
Notifications fire only for new unique detections — duplicate image loads never notify twice.
When on, the server skips storing IP addresses from tracking-pixel requests for your account. Detection still works; per-network analytics become less precise.
The server always keeps your full history — this only limits how many emails this browser profile caches locally.

What “detected” means

Email tracking detects image loading — via Gmail's image proxy or directly. It cannot guarantee that a person read the message. “Estimated unique” is a conservative deduplicated count; the raw event count is kept for transparency.
